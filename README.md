# صوت يجمعنا — Professional Voice Rooms UI

نسخة Front-end احترافية مستوحاة من الصورة المرجعية المرفوعة، بدون Backend أو نظام دفع/صوت حقيقي في هذه المرحلة.

## التشغيل
- افتح `index.html` للعرض.
- افتح `editor.html` للتحرير البصري المحلي.
- عدّل النصوص والألوان وارفع صور العناصر التي تحتوي على صورة.
- ملف `assets/reference.png` هو الصورة المرجعية الأصلية.

## الربط لاحقاً
الواجهة مصممة بحيث يمكن ربطها لاحقاً بـ API / WebSocket / WebRTC / قاعدة بيانات / مصادقة / مدفوعات.

## ملاحظة
المحرر الحالي يحفظ تعديلات العرض محلياً في المتصفح. لتكون التعديلات مشتركة على جميع الأجهزة يلزم إضافة Backend/Storage في المرحلة التالية.
